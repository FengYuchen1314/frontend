## 第一阶段改动

- 接入固定版本 HeroUI 3.2.4、Tailwind CSS 4.3.3、React Hook Form 7.87.0 和 Zod resolver。保留原目录、路由、API 契约与现有 React Query、Zustand 会话边界。
- 登录、首次注册、OAuth 按钮及回调、Passkey 按钮改用 HeroUI 原生组件。表单、错误映射及 OAuth 工作流拆入对应业务 model；保留服务端认证开关、品牌、密码生成/复制、返回地址和旧会话结果隔离。
- 快捷打开和实体深链保留全部八类实体映射、校验、Enter 提交、复制及导航。404 和 500 保留返回动作、错误栈展开和复制。
- Page 改用原生 DOM 属性并保留品牌标题、动画和减少动态效果偏好。LoadingScreen 改为 HeroUI ProgressBar，真实进度 0 不再被视为无值，未知进度显示不确定状态。
- 路由和下载进度使用独立任务 token，避免一个任务结束时清掉其他任务的进度。断线提示保留真实探测、退避和取消/旧会话保护；收到 HTTP 错误响应只表示链路可达，不代表后端健康。
- 语言选择、React Aria locale、文档语言/方向、主题读取及移动端媒体查询采用原生接线；保留四种语言和旧主题偏好读取。
